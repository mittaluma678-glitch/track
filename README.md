NutriTrack – Student Nutrition & Wellness Platform

About the Project

NutriTrack is a student-focused nutrition and wellness web application designed to help users track their daily food habits, water intake and nutritional activities.

It aims to promote healthy eating habits and improve awareness about daily nutrition.

Key Features

- Daily food and meal tracking
- Water intake monitoring
- Nutrition and wellness dashboard
- Weekly progress tracking
- Healthy lifestyle awareness
- Student Wellness Hub

Technologies Used

- Frontend: React, HTML, CSS, JavaScript
- Build Tool: Vite
- Backend: Node.js and Express.js
- Database: MongoDB
- Version Control: GitHub
- Frontend Hosting: Cloudflare

Project Structure

- "src/" – Frontend source code
- "server/" – Backend source code
- "index.html" – Main HTML file
- "package.json" – Project dependencies and scripts

How to Run the Project

1. Install Node.js on your computer.
2. Clone this repository:
   "git clone https://github.com/mittaluma678-glitch/track.git"
3. Open the project folder.
4. Install dependencies:
   "npm install"
5. Start the frontend:
   "npm run dev"

Backend

The backend is developed using Node.js and Express.js. It handles server-side operations and can be started using:

"npm run server"

Configure the required environment variables before running the backend.

Deployment

The project frontend is hosted using Cloudflare. The backend deployment is planned using Render.

Project Objective

The main objective of NutriTrack is to encourage students to understand their nutrition habits and develop a healthier lifestyle through digital tracking.
